## 为什么需要您录宏（无宏不猜）

pattern / rib / combine / AutoBalloon 四族此前累计 45+ 个直探变体全部静默失败
（tools/INDEX.md N9/N29/N30/N32 取证，"T8 静默族"）。录制宏是 SolidWorks 亲自
告诉我们它在 UI 背后调用的确切 API 序列与参数——这是唯一可靠的解锁钥匙。

## 通用步骤（任一族都一样）

1. 启动 SolidWorks 2026，新建一个零件（`文件→新建→零件`）。
2. 先随便做一个基体（例如画矩形→拉伸 10mm 凸台）——这一步**不要录**。
3. 菜单 `工具→宏→录制`（开始录制）。
4. 只做**一次**目标操作（见下表），参数随意但别省略。
5. 菜单 `工具→宏→停止`，保存为 `.swp` 到任意位置
   （建议 `E:\SolidWorks 2026\SolidWorksMCP\macros\`）。
6. 不需要保存零件文件。
7. 把 .swp 路径发给 AI 一句话即可。

## 四族操作指引（任选一族，推荐 pattern）

| 族 | 推荐操作 | 步骤 | 关键点 |
|---|---|---|---|
| **pattern**（推荐） | 圆周阵列一个孔 | 基体上先打一个 ⌀8 孔（不要录）→ 录制开始 → `插入→阵列/镜向→圆周阵列` → 阵列轴选「临时轴」（视图→临时轴可见）或基准轴 → 要阵列的特征选孔 → 实例数 4、等距 360° → ✔ | 阵列轴的选法正是宏要揭示的关键 |
| **rib**（筋） | 一条中心加强筋 | 做 L 形开口腔体（不要录）→ 在腔体上方基准面画一条贯穿线段 → 录制开始 → `插入→特征→筋` → 厚度 3mm、两侧对称 → ✔ | InsertRib 不可用（README 边界），宏揭示真正前置条件 |
| **combine**（组合） | 两实体并集 | 画两个交叠矩形→分两次拉伸凸台且**取消 Merge 结果**（不要录）→ 录制开始 → `插入→特征→组合` → 类型「添加」→ 选两个实体 → ✔ | body 级 NonApiBody 语义墙待宏定谳 |
| **AutoBalloon** | 装配图自动气球 | 开任一装配 + 由它建的工程图 → 录制开始 → `注解→AutoBalloon` → 选一个视图 → ✔ | BOM 表已通（N32），此族是最后缺口 |

## 备选交付格式

如果 .swp 保存遇到问题：录制停止后 `工具→宏→编辑`，在 VBA 编辑器里全选复制，
粘贴存成 `.txt` / `.bas`，或另存 `.swb`——管线对四种格式一视同仁。
