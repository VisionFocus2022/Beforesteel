> **版本**：v1.0（2026-10-04 立项）
> **程序判型**：**新建型**（独立新仓、新 MCP server）→ 策略=骨架优先（先立契约与测试护栏，再长能力）

> **关联**：`docs/prd-beforesteel-mcp.md`（Wave 1 L3 PRD）

## 1. 波次分解（滚动窗口：近细远粗）

### 波次 1 — factoryforge-mcp MVP（当前波）

**范围**：PRD v1.0 全部 P0 + P1（FR-001~009）。
**定径**：≈2-3 个会话窗口；超则拆（拆点：契约+场景+tag 读写为一波半，grader+故障/强制为一波半）。
**排序依据**：依赖拓扑（引擎会话→场景→tag→grader）+ 降险前置（骨架与测试护栏先于能力堆叠）。
**DoD（可判定，挂钩 PRD 成功指标）**：
- [x] 种子任务闭环率 ≥80%（3-5 个种子任务首过）——**3/3=100%**（seed1/2/3 首过，87 断言；首过史台账 output/seed-tasks.md，2026-10-05 W9 复跑仍 3/3）
- [x] headless grade 18/18 verdict 可得（PASS 或诚实 FAIL）——**18/18 PASS**（lockstep 11.3s，output/grade-panorama.md，W4 产出）
- [x] 计数锁 + capabilities 锁 + mock 总线全绿；coverage ≥80%——**pytest 113 passed；coverage TOTAL 87%**（branch，fail_under=80；W9 全量回归复核）
- [x] 主仓 CI 维持绿（小步并行验收面）——夜间零触碰，晨验 git status（2026-10-05 晨实测：仅既有 docs 级工作树条目，无任何代码/测试/CI 改动）
- [x] MIT NOTICE 归属声明随仓——NOTICE 在盘（T1 交付，W8 核验）

### 波次 2 — CAD 闭环（远期，粗）

**范围**：FR-101 布局导出器 + FR-102 仿真反馈报告。
**前置**：波次 1 DoD 全过 + Q-4 布局语义映射定档（届时独立 PRD，落主仓或 aicad 侧文档）。
**触发再评估**：波次 1 收官时按预验尸 #4 信号决定推进/合流/封存。
