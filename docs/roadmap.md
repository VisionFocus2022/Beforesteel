# SolidWorksMCP 产品路线图

> 2026-10-02 创建。按 MoSCoW 框架（Must/Should/Could/Won't）组织。
> 当前版本：v0.3.0（81 工具 / 594 测试 / 87% 覆盖率）

## v0.4 — 能力扩展（目标 2026-Q4）

| 优先级 | 功能 | 说明 | 预估工作量 |
|--------|------|------|-----------|
| Should | 复杂草图约束 | 草图几何约束（同心、相切、固定尺寸）暴露为工具 | 5 人天 |
| Should | 曲面基础 | 拉伸曲面、旋转曲面、缝合为实体 | 5 人天 |
| Should | STEP 双向导出增强 | 装配体 STEP 导出 + STEP 导入保留特征树 | 3 人天 |
| Could | 线性阵列 | 矩阵阵列沿方向阵列特征 | 2 人天 |
| Could | 草图驱动阵列 | 草图点驱动阵列 | 2 人天 |

## v0.5 — 装配增强（目标 2027-Q1）

| 优先级 | 功能 | 说明 | 预估工作量 |
|--------|------|------|-----------|
| Must | 完整装配约束 | 支持所有 SW mate 类型（角度、宽度、对称、路径） | 5 人天 |
| Should | 装配体干涉检查 | 暴露 InterferenceDetectionManager | 2 人天 |
| Should | BOM 自动生成 | 装配体 BOM 表导出 CSV/Excel | 3 人天 |
| Could | 爆炸视图自动化 | 爆炸步骤记录 + 参数化爆炸 | 2 人天 |

## v1.0 — 生产就绪（目标 2027-Q2）

| 优先级 | 功能 | 说明 | 预估工作量 |
|--------|------|------|-----------|
| Must | GD&T 形位公差框格 | 工程图中标注形位公差 | 5 人天 |
| Must | 工程图 BOM 表 | 工程图自动 BOM + 序号标注 | 3 人天 |
| Must | PDF/STEP/STL 批量导出 | 装配体全件批量导出 | 2 人天 |
| Should | 材料库管理 | 自定义材料属性 + 截面属性计算 | 3 人天 |
| Should | 方程式与全局变量 | 暴露 EquationManager | 2 人天 |

## Won't（明确不在范围）

- 运动仿真与动画（Motion Study）
- 有限元分析（FEA / Simulation）
- PDM / PLM 集成
- 钣金特征
- 管道/电气布线
- 模具设计

> 这些能力超出 MCP 工具定位（参数化建模 + 装配 + 工程图导出），
> 用户如有需求应直接使用 SolidWorks 原生功能。

## aicad 子仓路线图

| 版本 | 功能 | 状态 |
|------|------|------|
| 当前 | build123d 沙箱 + 52 eval + React 前端 | ✅ 已完成 |
| 下一步 | SW COM 桥三通道增强（STEP + 特征树 + 参数同步） | 规划中 |
| 未来 | 多用户协作 + 版本链可视化 + 标准件库扩展 | 待规划 |

## 版本节奏

- **Minor 版本**：每月一个（功能新增）
- **Patch 版本**：按需发布（bug 修复）
- **Major 版本**：季度评估（v1.0 生产就绪里程碑）
